# Glitch ML

Learn to code machine learning in small steps: NumPy, pandas, scikit-learn and PyTorch.
Each chapter has a short lesson, then seven ways to test yourself: fill in the missing code, predict the output, put lines in order, find the bug, pick the right tool, a 60-second true/false round, and a 10-question exam.

Runs entirely in the browser; progress is saved on your device.

Releasing: bump `APP_VERSION` in `index.html` and `VERSION` in `sw.js`, then push.
